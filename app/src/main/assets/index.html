Repo Sync

Your GitHub token stays in your browser. It is never sent to any server except GitHub.

Use a fine-grained token limited to your repo with "Contents: Read and write" permission.

Steps to create a Fine-Grained Token:
  1. Go to GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token.
  3. Under Repository access, select Only select repositories and choose your repository.
  4. Under Repository permissions, expand Contents and choose Read and write.
  5. Click Generate token and paste it into the field above.
